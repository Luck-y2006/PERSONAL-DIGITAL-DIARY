# 📔 Personal Digital Diary

A personal productivity and idea-management application designed to help you organize your thoughts, remember your goals, and track your progress.

## 🎯 Project Overview

**Personal Digital Diary** is more than a digital notebook. It is a personal space where you can record your ideas, manage your goals, and keep track of your personal progress.

The main objective is simple:

*Write down your goals so you never forget them, track your progress, and turn your ideas into reality.*

## ✨ Key Features

- **Goal Management:** Create and organize personal goals.
- **Progress Tracking:** Monitor the status of your goals.
- **Status Management:** Identify goals as:
  - 🟢 Completed
  - 🟡 In Progress
  - 🔴 Ended
- **Idea Management:** Record and organize your ideas.
- **Search Functionality:** Quickly find previously saved ideas.
- **Personal Organization:** Keep your goals and ideas organized in one place.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open the main HTML file in your browser.

## 📂 Project Purpose

This project is being developed to make personal planning easier, more organized, and more meaningful.

It focuses on three important things:

1. **Remember:** Never lose track of your goals and ideas.
2. **Track:** Know what you have completed and what is still in progress.
3. **Improve:** Monitor your journey and keep moving forward.
